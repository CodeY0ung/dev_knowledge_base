# Sequence · Identity 컬럼

**학습: 9/15, 9/21~22**

```sql
CREATE SEQUENCE smember_seq START WITH 1 INCREMENT BY 1 NOCYCLE;
INSERT INTO sample_member(mno, mname)
VALUES (smember_seq.NEXTVAL, 'b');
SELECT smember_seq.CURRVAL FROM dual;
```

- `NEXTVAL`: 다음 시퀀스 값 생성.
- `CURRVAL`: 현재 세션에서 생성한 최신 값 조회(먼저 NEXTVAL 사용 필요).
- `CACHE`, `NOCYCLE` 등의 속성 실습.

```sql
CREATE TABLE test04 (
    mid NUMBER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    mname VARCHAR2(20)
);
CREATE TABLE test05 (
    mid NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    mname VARCHAR2(20)
);
```

- `GENERATED ALWAYS`: 일반 INSERT에서 식별자 직접 지정 제한.
- `GENERATED BY DEFAULT`: 식별자 직접 지정 가능.
- 시퀀스 값은 결번이 발생할 수 있으므로 연속성을 보장하는 번호로 취급하지 않는다.
